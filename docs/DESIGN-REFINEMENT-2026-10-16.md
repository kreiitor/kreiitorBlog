# 群青与朱橙：2026-10-16 研究作品集重设计

## 设计约定

面向希望了解作者、阅读技术文章和系统学习的访客。目标是有张力而优雅的撞色、明确的编辑层级、专属标记与细致交互；完整阅读和静态导航能力是基础。

- 配色：暖纸白 `#F7F3EB`、深墨 `#232739`、群青 `#293CCB`、朱橙 `#E65D3B`、杏橙 `#F6B18F`、卡片 `#FFFDF8`。群青承担操作与首屏视觉重心，朱橙用于背板、索引线与图形节点；小号橙色文字使用更深的 `#A63B25`。暗色为午夜蓝背景、浅蓝操作与暖橙点缀。
- 字体：中文标题使用现有思源宋体 600；英文标题使用 Lora；正文使用 Source Serif 4 / 思源宋体；界面使用 DM Sans / 系统中文；代码沿用 JetBrains Mono。复用本地字体，不增加远程字体请求。
- 布局：首屏大标题与较小的插画形成非对称比例，橙色背板强化视觉重心。精选以图文主篇配两条文字推荐，学习区使用与页面相同的底色，以缩略图、横向索引和细线改变节奏，项目采用错位的大图展示。近况与话题索引形成收尾。手机重新堆叠栏目标题、入口、专题与项目，保留清晰点击区域。
- 标记：几何 K 的字干与分叉构成主体，朱橙方点作为索引。纯矢量母版同时生成页头、头像、favicon 与分享图，暗色页头提亮主笔画。
- 动效：首屏文字分层入场；专题与项目一次性轻移入场；导航下划线、推荐分隔线、箭头和按钮响应悬停、焦点与按压。减少动态效果时关闭首屏和插画动画，并取消进行中的 Web Animations。滚动不改变页头高度。

## 技能应用与取舍

- `frontend-design`：先固定配色、字体、内容与网格；删掉无顺序含义的栏目编号，减少重复英文标记。以研究内容而非营销组件组织首页。
- `web-design-guidelines`：按最新规则审查焦点、长标题、主题色、菜单溢出、触控和减少动态效果。子智能体负责独立审查与手机菜单修复。
- `ui-ux-pro-max`：实际查询标题平衡、触控目标、Astro 静态导航，以及 editorial / portfolio 配色与高对比风格。采用学术排版、清晰网格与中性阅读底的原则；最终蓝橙组合经过真实首页的三组对比与编辑判断，并非照搬数据库默认色板。
- `playwright`：真实浏览器截图对比、交互检查，并执行仓库已有浏览器回归。截图与临时下载保存在忽略目录 `.artifacts/`。

## 最新审视修复与复核

- 手机栏目说明使用可用整行宽度，精选说明精简为“从问题出发，把方法与实践写清楚。”；320px 与 390px 下无单字落行。
- 平板插画底部说明按完整短语换行。768px 下两段各为单行 21px，避免“作”“证。”被单独挤到下一行。
- 首页学习索引改用三张专用无字 SVG：统计曲线、Agent 节点、基础设施分层。沿用语义配色并完整缩放，解决大封面缩小裁字问题。
- 手机首篇精选先展示标题摘要，再展示封面。390×844 下标题顶部由约 1052px 提前到 764px；短栏目标题与入口同排，长栏目继续自然堆叠。
- 搜索清空输入后移除完整搜索链接中残留的 `q`。实测连续新标签页分别打开 `/search/?q=LLM` 与 `/search/`。
- 原生移动菜单移除静态 `aria-expanded="false"`；禁用 JavaScript 后仍可展开并访问文章归档，启用脚本时继续同步展开状态。
- 对最终代码重新执行完整浏览器回归：87 项通过、1 项按预期跳过；Astro、单元与系列校验、生产构建及 `git diff --check` 全部通过。
- 发布方式：提交并推送 GitHub `master`，由现有 GitHub Actions 工作流重新构建并部署 GitHub Pages；实际部署结果以工作流记录为准。
