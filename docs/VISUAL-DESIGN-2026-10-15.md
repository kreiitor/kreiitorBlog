# 视觉设计：奶油白、钴蓝与酸柠黄

这轮调整将站点收敛为研究札记与编辑式作品集：正文保持安静，首屏有明确的色彩重心，文章、专题与项目各有不同的呈现方式。

## 配色

| 角色 | 浅色 | 暗色 |
| --- | --- | --- |
| 页面 | `#F7F6F2` 奶油白 | `#151A27` 深海军蓝 |
| 卡片 | `#FFFEFA` | `#1D2537` |
| 主文字 | `#18243A` | `#EFF2FA` |
| 主操作、关键链接 | `#2448D8` 钴蓝 | `#B6C7FF` |
| 小面积强调 | `#E5EE95` 酸柠黄 | `#E5EE95` |

大面积中性色承载内容；钴蓝用于首屏插画、主按钮与精选标题；酸柠黄用于眉题、精选标记和插画纸张呼应，避免每个组件同时抢夺注意力。全站颜色集中在 `src/styles/global.css`；首页插画保留独立的纸张与画布语义令牌。

## 页面与组件

- 首页首屏缩短；精选改为标题在前、插画在后的主卡，搭配两条文字推荐。
- 首页推荐集中在 `src/data/site.ts` 的 `homeFeaturedPosts`，同时配置文章标识与显示标签。只展示已发布文章，缺失时补充其他精选。
- 首页顺序为简介、精选、学习专题、项目、最近更新；学习卡去掉重复的大圆形徽记，项目改成小插画与成果介绍并排。
- 手机博客筛选为两列；学习路径使用原生 `details`，默认折叠，选择系列学习时展开。无 JavaScript 时仍可原生展开。
- 教程与课程正文前取消装饰性大封面；分享图继续保留。研究随笔使用较矮的封面。
- 保留首页文楷大标题，列表、组件与文章标题使用宋体层级。

## 插画与分享图

30 张 SVG 封面在文件内部声明浅色、暗色变量。浏览器通过继承页面的 `color-scheme` 选择 SVG 内的媒体查询，因此系统主题、手动切换及禁用 JavaScript 都沿用同一份资产。显式浅色也设置 `color-scheme: light`，保证其优先于系统暗色。

分享 PNG 固定使用浅色版本。`scripts/prepare-social-images.mjs` 在交给 sharp 前展开 SVG 的浅色变量，避免 librsvg 不支持 CSS 自定义属性导致的黑图。

重新生成：

```sh
npm run art:prepare
```

头像、favicon、分享卡、评论面板与代码块使用对应的蓝色系。

Logo 采用钴蓝底的打开书页，以折线路径和酸柠黄节点表达从阅读到探索。矢量母版为 `public/logo.svg`；页头直接内联母版，头像、SVG/ICO favicon 与分享卡中的标记由同一母版生成。修改母版后运行 `npm run brand:prepare`，避免不同位置的标记发生偏差。

## 验证

验证包含 Astro 静态检查、单元与系列测试、生产构建、内部引用与公式检查，以及桌面和手机的浏览器回归。新增 `tests/browser/design.spec.mjs` 覆盖首页内容位置、精选多样性、手机学习专题展开行为、封面随手动主题切换的实际像素，以及教程直接进入正文。

视觉截图保存在忽略目录 `.artifacts/aesthetic-review/`。主题测试保留首帧防闪、存储不可用与无 JavaScript 场景；对比度测试使用浏览器实际文字色与合成背景色验证 AA。Windows 上 Astro 的开发、检查和构建共享内容缓存，应顺序执行会写缓存的命令，避免文件重命名竞争。
