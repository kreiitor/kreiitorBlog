# UI 审查复核与修复 · 2026-10-18

依据 [原审查报告](UI-REVIEW-2026-10-18.md)逐项核对源码与浏览器行为。报告截图对应的本地版本落后于 GitHub `master` 的 `1523966`；本次先合并远端更新，在最新代码上修复并保留新标志、阅读结构和已完成的响应式工作。用户随后要求重新打磨色彩与首页体验，本地已迭代为钴蓝与日光黄，详见 [首页设计记录](HOME-DESIGN-2026-10-18.md)。用户随后确认封面重构并恢复 GitHub master 发布。

## 功能与可用性

- **项目阅读工具**：移到详情页正文列、标题下方。工具初始化前隐藏，初始化后展示；阅读位置仍须主动开启，数据只保存在本机。
- **搜索误命中**：实测 `zzzzzzzz` 被 Pagefind 归一化为公式中的 `Z`。现在对候选的标题、摘要和真实正文进行核验，过滤无关结果，同时保留 `Fischer` 这类仅出现在正文中的搜索结果。补充对应单元回归。
- **搜索分页与弹窗**：保留已有“查看更多”按钮，区分已显示数量与尚可加载的候选；输入非空时一次 Esc 即关闭并恢复触发器焦点。结果区独立滚动，快捷键页脚固定；结果标题在弹窗内使用 h3，完整搜索页使用 h2。
- **搜索初始状态**：提供最近更新与常写话题，输入有效查询后收起推荐。
- **手机导航**：移除内部链接的外链箭头，面板从实际页头底部展开，增加可点击遮罩；保留远端的安全区内边距、横屏滚动与无 JavaScript 导航。进入桌面断点自动收起。
- **可点击区域**：页脚链接、搜索建议、阅读记录按钮和移动目录 summary 至少 44px 高；标题锚点有独立点击区域，触屏下进一步扩大；标签和箭头也扩充触控区域。
- **标题结构**：为基础 h1 补齐字号；正文标题独立使用 30–48px 的响应尺寸。列表卡片按所在层级输出 h2 或 h3，独立札记列表使用 h2。
- **章节导航**：仅有上一章或下一章时占完整一列，左对齐。
- **链接方向**：站内菜单、最近文章、话题、学习路径、项目侧栏、归档、搜索入口、404 返回入口统一使用站内方向。

## 排版与视觉

- **首页和平板**：hero 与精选内容在 900px 以下改为单列；首屏改为可以进入真实札记、论文阅读与实验工作台的问题卡；手机保留三个完整点击入口，移除被裁切的小图与微小标注。
- **手机项目卡**：所有项目卡在手机上使用横向配图和下方正文，消除窄长的竖向封面。首页沿用远端横向项目展示；项目列表采用同样清晰的手机结构。
- **学习专题**：沿用首页学习索引布局，缩略图替换为统一重绘的黄蓝几何封面；普通专题卡使用同一图稿，避免维护两套不一致的插画。
- **正文与目录**：桌面正文最多 800px，目录使用剩余宽度，间隔固定为 48px；移除 `space-between` 造成的额外间隙。窄屏继续使用单列与移动目录。
- **暗色**：主按钮使用饱和蓝配白字，问题卡保留黄蓝对比，正文使用午夜蓝的安静阅读背景。
- **画廊**：独立标题与导语，瀑布流按照片原比例排版；竖图不再跨列进入巨大白框。点击打开原图弹窗，支持按钮、左右方向键、Esc、关闭后恢复焦点；关闭 JavaScript 时仍可直接进入图片。
- **归档**：左侧导语与右侧年份形成分栏，按月份分组；月份标题固定，日期只显示日，方向提示在悬停或键盘焦点时显示。
- **话题**：紧凑索引替代重复大卡片；`cpp` 归并为 `C++`，`algorithms` 归并为“算法”，旧地址继续生成。只展示非零的札记/项目计数。
- **其他**：去掉概况数字的零填充；保留等宽数字。删除关于页重复的兴趣列表；项目页附注成为有明确归属的说明；评论初始状态说明按需连接。
