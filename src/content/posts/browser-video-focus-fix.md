## 这篇文档解决什么问题

在浏览器里看短视频流或类似可连续滑动的网页时，切换到其他窗口后再切回原窗口，页面可能会失去焦点。表现通常是：

- 方向键、空格、`PageDown` 不能继续切换下一个视频
- 鼠标滚轮滚动没有反应，或滚动目标不再是视频流区域
- 必须用鼠标点一下页面，键盘和滚轮才恢复正常

这篇文档记录不依赖鼠标点击的恢复方法，优先使用键盘把焦点切回网页内容区域。

---

## 推荐排查顺序

### 1. 切回窗口后先按 `Esc`

最简单的操作是：

```text
Alt + Tab 切回浏览器窗口 -> Esc -> 方向键 / Space / PageDown
```

`Esc` 常见作用：

- 退出地址栏焦点
- 关闭轻量弹层或快捷键提示
- 让焦点从页面控件回到网页内容区域

如果只是焦点停在地址栏、弹层、按钮或视频控件上，按一次 `Esc` 通常就能恢复。

### 2. 使用 `F6` 在浏览器焦点区域之间切换

如果 `Esc` 无效，可以按 `F6`。

浏览器里的 `F6` 通常会在这些区域之间循环切换焦点：

- 地址栏
- 标签栏或工具栏
- 网页内容区域

推荐操作：

```text
F6 -> 如果焦点到地址栏则按 Esc -> 再试方向键 / Space / PageDown
```

有时需要按多次 `F6`，直到焦点回到网页内容区域。

### 3. 用 `Tab` / `Shift + Tab` 移动到页面元素

如果页面内部有按钮、视频区域、播放器控件或可聚焦元素，可以用：

```text
Tab
Shift + Tab
```

当焦点移动到页面内元素后，再尝试：

```text
Space
方向键 ↓ / ↑
PageDown / PageUp
```

这种方式适合页面本身支持键盘导航的情况。

## 备用方法

### 1. Windows 鼠标键模拟点击

如果网页必须接收一次点击才能恢复焦点，但不想动鼠标，可以使用 Windows 的“鼠标键”。

开启快捷键：

```text
Alt + 左 Shift + Num Lock
```

开启后，小键盘常用操作：

```text
小键盘 5 = 左键点击
```

这本质上还是一次点击，但全程可以只用键盘完成。

### 2. AutoHotkey 绑定一个键模拟点击

如果这个问题很频繁，可以用 AutoHotkey 绑定一个按键，例如 `F8` 模拟点击当前鼠标位置。

```ahk
F8::Click
```

使用方式：

```text
Alt + Tab 切回浏览器 -> F8 -> 继续用方向键或滚轮切换视频
```

这个方案适合长期使用，但需要提前安装并运行 AutoHotkey 脚本。

---

## 实用结论

优先尝试下面这个顺序：

1. `Alt + Tab` 切回窗口后按 `Esc`
2. 如果无效，按 `F6`，必要时再按 `Esc`
3. 如果仍无效，用 `Tab` / `Shift + Tab` 把焦点移回页面元素
4. 如果页面必须点击，使用 Windows 鼠标键或 AutoHotkey 模拟点击

最常用组合是：

```text
Alt + Tab -> Esc -> ↓ / Space / PageDown
```

如果这个组合不稳定，再使用：

```text
Alt + Tab -> F6 -> Esc -> ↓ / Space / PageDown
```

---

## 注意事项

- 不同浏览器和网站的焦点处理不完全一致，`Esc` 和 `F6` 的效果可能不同。
- 如果页面里有弹窗、评论输入框、搜索框或播放器控件，键盘事件可能会先被这些元素截获。
- 如果网站本身要求用户点击页面后才启用某些交互，只靠 `Esc` / `F6` 可能无法完全替代点击。
- AutoHotkey 模拟点击时，点击位置取决于当前鼠标停留位置，最好让鼠标平时停在视频区域内。
