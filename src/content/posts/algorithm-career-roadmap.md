## 这篇文档解决什么问题

这篇文档主要回答一个现实问题：

在 AI 时代，如果目标是进入“前沿算法岗”，从零开始到底该学什么、先学什么、做到什么程度才像能投递的人。

这里的“前沿算法岗”不是泛指任何会调包的 AI 岗位，而更接近下面这些职位：

- Research Engineer
- Machine Learning Engineer
- LLM / 多模态算法工程师
- 训练系统工程师
- 评测与后训练工程师

这篇文档的目标不是讲励志，而是帮你建立一个可执行的能力路线。

---

## 前沿算法岗现在到底指什么

截至 `2026-05-11`，公开岗位里所谓“前沿算法岗”，本质上已经越来越像 `研究工程 + 训练系统 + 实验能力` 的混合体。

从当前公开岗位看，头部实验室和公司更关注这些方向：

- 预训练（pretraining）
- 后训练（post-training）
- 评测（evals）
- 强化学习（RL / RLHF）
- 推理与部署性能优化
- 多模态模型
- 训练基础设施与分布式系统

也就是说，现在真正值钱的，不只是“会用模型”，而是：

- 能把模型训练起来
- 能把实验做严谨
- 能把系统跑稳定
- 能解释结果并继续迭代

## 这些岗位共同要求的核心能力

根据当前公开岗位和官方职业页面，可以把核心能力概括成 7 类。

### 1. 软件工程基本功

这是底座。

你至少要能稳定使用：

- Python
- Linux 基本命令
- Git
- 调试与日志排查
- 可复现实验流程
- 基础代码组织能力

很多人误以为算法岗只看数学，其实当前很多前沿岗位首先筛掉的是工程基本功不行的人。

### 2. 数学与机器学习基础

你不一定要先把全部数学学完，但至少要能支撑你理解训练过程。

最低应具备：

- 线性代数
- 概率统计
- 微积分
- 优化基础

对应到实际问题，就是你至少要能理解：

- loss 是什么
- 梯度为什么能更新参数
- 为什么会过拟合
- 为什么评估指标会影响结论

### 3. 深度学习框架能力

当前最关键的是 `PyTorch`。

你不能只停留在“会 import 一个模型”，而要能自己完成：

- 数据加载
- 模型定义
- 训练循环
- 反向传播
- 优化器配置
- checkpoint 保存与恢复

### 4. LLM / Transformer 能力

当前算法岗的核心知识栈，已经大量围绕 Transformer 和大模型展开。

要逐步掌握：

- tokenizer
- Transformer 基本结构
- pretraining / SFT / adapter
- 数据清洗与构建
- 评测流程
- 推理与部署

### 5. 系统与规模化能力

这部分是很多人低估的。

当前前沿算法岗非常看重：

- GPU 使用
- 显存与吞吐优化
- 多卡训练
- 分布式训练基础
- 数据处理流水线
- 推理服务与性能测试

如果你只会“单卡跑一个 notebook”，通常还离前沿岗位比较远。

### 6. 科研与实验能力

真正的算法岗不是只把代码跑通，而是要能：

- 读论文
- 复现实验
- 设计对比实验
- 做 ablation
- 分析失败原因
- 判断结果是否可信

这部分能力决定你是不是“会做实验的人”。

### 7. 沟通与协作能力

前沿岗位并不只是闭门写模型。

你还需要能：

- 清楚地写技术文档
- 和工程、产品、研究同事协作
- 讲清楚 trade-off
- 汇报实验结果

很多岗位其实会更偏好“能把东西讲清楚的人”，而不是只会堆术语的人。

## 从零开始的阶段路线

下面给一条更现实的路线。不是唯一正确答案，但比较稳。

### 第 0 阶段：0 到 2 个月

目标：

- 补齐最低配基础
- 建立编程和工具链习惯

重点：

- Python
- Git
- Linux 基础
- Numpy
- 基础数学直觉

阶段标准：

- 能自己写中等长度 Python 脚本
- 会用 Git 管理代码
- 会读和改简单训练脚本

### 第 1 阶段：2 到 4 个月

目标：

- 真正理解基础机器学习与深度学习

重点：

- 线性/逻辑回归
- MLP
- CNN
- loss、优化器、正则化、过拟合
- 训练/验证/测试的区别

阶段标准：

- 能不靠魔法封装写出基础训练循环
- 能解释模型为什么表现好或差

### 第 2 阶段：4 到 7 个月

目标：

- 进入 Transformer / LLM 栈

重点：

- 自注意力机制
- Transformer 结构
- tokenizer
- 数据集处理
- 微调与评测

阶段标准：

- 能跑通一个小型 LLM 微调流程
- 能解释 prompt、数据和参数改动对结果的影响

### 第 3 阶段：7 到 10 个月

目标：

- 做出像岗位能力的项目

建议至少完成 3 类项目：

1. 一个从零实现的 mini Transformer 项目
2. 一个 LoRA / SFT / 评测项目
3. 一个性能优化或部署项目

阶段标准：

- 不是只会跑 demo
- 而是有完整 repo、实验记录、结果分析和失败复盘

### 第 4 阶段：10 到 18 个月

目标：

- 确定自己的主方向

这个阶段要开始分化：

- 应用型 LLM 算法岗
- 训练系统 / 性能优化岗
- 预训练 / 后训练 / evals
- 多模态
- 强化学习 / RLHF

阶段标准：

- 你能清楚说出自己想投什么方向
- 你的项目开始围绕这个方向形成组合

## 应该做什么项目，才像能投递的人

很多人学了很多课程，但项目像作业，不像岗位能力证明。

更像可投递候选人的项目，通常具备这几个特点：

### 1. 有完整流程

至少包括：

- 数据准备
- 训练
- 验证
- 结果展示
- 误差分析

### 2. 有对比实验

不是只贴一个最好结果，而是能说明：

- 为什么改这个
- 和基线差多少
- 为什么变好或变差

### 3. 有工程化痕迹

比如：

- 配置文件
- 日志
- checkpoint
- 可复现实验命令
- README

### 4. 有明确主题

建议做这类项目：

- `mini Transformer`：证明你理解模型结构
- `LoRA/SFT 项目`：证明你理解数据与微调
- `LLM eval 项目`：证明你能设计评估
- `性能优化项目`：证明你不是只会调包

### 5. 能讲清楚 trade-off

例如：

- 效果 vs 显存
- 速度 vs 精度
- 数据量 vs 收益
- 工程复杂度 vs 模型提升

这类说明，比单一指标更像真实岗位需要的思维。

## 不同方向如何选择

### 1. 想尽快就业

优先：

- 应用型 LLM 算法岗
- 大模型微调 / Agent / RAG 方向

特点：

- 学习门槛相对低
- 岗位量通常更多
- 更偏工程落地

### 2. 想建立更强壁垒

优先：

- 训练系统
- 推理优化
- 分布式训练

特点：

- 难度更高
- 工程壁垒更强
- 越往上走越稀缺

### 3. 想冲最前沿实验室

优先：

- pretraining
- post-training
- evals
- interpretability
- RL / RLHF

特点：

- 要求更高
- 对实验能力、系统能力和研究能力都更敏感
- 更像 Research Engineer 路线

## 现实时间预期

这部分要现实一点。

### 从纯零基础开始

如果你是完全零基础，比较合理的预期是：

- 到能投应用型 AI / LLM 工程或算法岗：`9 到 15 个月`
- 到比较像前沿实验室候选人：`18 到 36 个月`

### 如果你已经有基础

如果你已经有这些中的一部分：

- 计算机专业背景
- Python 基础
- 数学基础
- 做过一些 AI 项目

整体时间会明显缩短。

关键不是时间绝对值，而是你有没有持续输出：

- 项目
- 文档
- 实验
- 代码记录

下面这几类资源更适合打基础和进入主线。

- [Dive into Deep Learning](https://d2l.ai/chapter_preliminaries/index.html)

优点：

优点：

## 常见误区

### 1. 以为算法岗主要看数学

现实是：

- 数学重要
- 但工程基本功和实验能力同样重要

很多人不是输在不会微积分，而是输在：

- 不会调试
- 不会复现实验
- 不会组织代码

### 2. 以为会调库就够了

只会调用封装，不会说明：

- 数据怎么处理
- 结果为什么变化
- 为什么这组实验可信

这种状态通常离真正算法岗还差得远。

### 3. 以为必须先学完所有基础再做项目

更现实的方式是：

- 基础和项目并行
- 一边学一边做

否则容易陷入长期输入、没有输出。

### 4. 以为只要刷论文就会变强

读论文重要，但如果没有：

- 实现
- 复现
- 对比实验
- 失败分析

那论文阅读很容易停留在“看过”。

### 5. 以为前沿岗位只收名校或 PhD

现实情况更复杂。

顶级实验室当然更偏好高水平背景，但真正关键的是：

- 你能不能做出像样的东西
- 你有没有稳定的项目和实验记录
- 你有没有持续构建能力

非传统路径不是没有机会，但不能只靠口头热情。

---

## 最短结论

如果你只想记住最关键的结论，可以只记这几条：

1. 现在的前沿算法岗，本质上是 `研究工程 + 系统能力 + 实验能力`
2. 从零开始，先补 `Python / Git / Linux / 数学直觉 / PyTorch`
3. 接着进入 `Transformer / LLM / 微调 / 评测`
4. 真正有竞争力的人，不是只会跑 demo，而是有完整项目和实验分析
5. 从纯零基础到能投递，通常至少按 `9 到 15 个月` 的尺度规划更现实
